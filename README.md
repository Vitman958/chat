# Чат-сервер с комнатами

[![Python](https://img.shields.io/badge/python-3.7%2B-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Простой многопользовательский чат на Python с поддержкой комнат, аутентификации и хранением истории сообщений.

## 🚀 Возможности

- Подключение к серверу
- Регистрация и аутентификация пользователей
- Переключение между комнатами
- Просмотр списка доступных комнат
- Отправка сообщений в текущей комнате
- Просмотр истории сообщений при заходе в комнату
- Система команд для взаимодействия с чатом

## 💡 Команды чата

| Команда | Описание |
|--------|----------|
| `/help` | Справка по командам |
| `/exit` | Выход из чата |
| `/connect [имя_комнаты]` | Присоединиться к комнате |
| `/leave` | Вернуться в главную комнату |
| `/rooms` | Список всех комнат |
| `/login [username] [password]` | Войти в профиль |
| `/register [username] [password]` | Зарегистрироваться |
| `/logout` | Выйти из профиля |

## 🏗 Архитектура

Проект состоит из следующих компонентов:

- **Client** - клиентская часть чата
- **Server** - серверная часть с обработкой подключений
- **Shared** - общие компоненты для клиента и сервера
- **Utils** - вспомогательные утилиты

### Структура проекта

```
chat/
├── client/                 # Клиентская часть
│   ├── main.py             # Точка входа клиента
│   └── handlers.py         # Обработчики клиента
├── server/                 # Серверная часть
│   ├── main.py             # Точка входа сервера
│   ├── handlers.py         # Обработчики сервера
│   └── server_setup.py     # Настройка сервера
├── shared/                 # Общие компоненты
│   └── command_handler.py  # Обработчик команд
├── utils/                  # Вспомогательные утилиты
├── requirements.txt        # Зависимости
└── README.md               # Документация
```

## 📦 Установка и запуск

### Предварительные требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск сервера

```bash
python -B -m server.main
```

### Запуск клиента

```bash
python -B -m client.main
```
