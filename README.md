# Чат-сервер с комнатами

[![Python](https://img.shields.io/badge/python-3.7%2B-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Простой многопользовательский чат на Python. Можно общаться в разных комнатах, регистрироваться, входить под логином и видеть историю сообщений.

🛠️Функционал чата:

1) Подключиться к серверу
2) Зарегистрироваться или войти по логину/паролю
3) Переключаться между комнатами (/connect, /leave)
4) Смотреть список комнат (/rooms)
5) Отправлять сообщения в текущей комнате
6) Видеть историю сообщений при заходе в комнату
7) Просмотреть команды (/help)
8) Выйти из чата (/exit)

⚙️ Как работает?
1) Запускаешь сервер, настраиваешь и ждёшь подключений.
2) Запускаешь клиент - вводишь логин (если есть - вводишь пароль, если нет - регистрируешься).
3) После входа - попадаешь в комнату general.
4) Можешь переключаться между комнатами командами /connect имя_комнаты и /leave.
5) Все сообщения сохраняются в базу данных - при заходе в комнату ты увидишь историю.
6) Если хочешь выйти - пиши /exit.

🧩 Особенности
1) Безопасность: проверка имени, логина и пароля, ограничение частоты сообщений.
2) История: при заходе в комнату показывается всё, что было написано ранее.
3) Готов к упаковке: можно собрать в .exe через PyInstaller.

📦 Как запустить?
1) Установка зависимости
   
       pip install -r requirements.txt
2) Запустить сервер

```bash
python -B -m server.main
```

### Запуск клиента

       python -B -m client.main
